# FroggyKit 🐸

Shared Swift 6 package for the [Froggy](https://github.com/froggychips/Froggy) ecosystem.

## What's inside

| Module | Contents |
|---|---|
| `FroggyKit` | `FroggyClient` — Unix socket IPC client for the Froggy daemon |

## Used by

- [froggy-mcp](https://github.com/froggychips/froggy-mcp)
- [froggy-sre](https://github.com/froggychips/froggy-sre)

## Add as dependency

```swift
.package(url: "https://github.com/froggychips/FroggyKit", branch: "main")
```
